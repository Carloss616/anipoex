# App icon

Every icon, splash and favicon file is generated by [`scripts/app-icon/build.ts`](../scripts/app-icon/build.ts) from one config. Never edit the generated files by hand: change the config and run `bun run icon:build`.

## The mark

A lowercase **a** and a **p** whose stem is a bookmark ribbon: the app's initials, and the place you left off in a manga.

- Drawn on a 1024 canvas in [`mark.ts`](../scripts/app-icon/mark.ts), fills only (rings are even-odd paths, the a's stem a rounded rect), since Icon Composer and the PNG renders take outlines.
- Both bowls are rings of radius 118 and weight 92. The stems reach the x-height (y 288) with round ends; the a's stem sits on its ring's right edge, the p's on its ring's left edge, 36 apart.
- The ribbon ends in a V notch 52 deep, its two points rounded (`tip` 24) and the inside of the V softened (`apex` 14).
- **Optical centering:** the mark is centered by the centroid of its ink, 12 px above the canvas center, not by its box. The box counts the thin descender and left the bowls 88 px high.
- A `small` size (weight 124, notch 76) is used at 32 px and below, so the ribbon still reads in a favicon.

## Colors

Violet with a magenta ribbon: two neighboring hues, so the icon reads as one color family. Each look keeps the same hues and changes only lightness.

| | Light | Dark |
|---|---|---|
| a | `#1A1A1A` | `#F5F1FF` |
| Ribbon (p) | `#C81E6E` | `#F0509A` |
| Background | `#FCFAFF` → `#E2D0FA` | `#221131` → `#8A52C4` |
| Splash | `#FCFAFF` | `#221131` |

The light ribbon is a deeper magenta: `#F0509A` gave 1.8:1 against the light glow. Keep every part of the mark at 3:1 or more against what it sits on (WCAG's minimum for graphics).

## Background

Built in this order, the same recipe in both looks:

1. **Vertical gradient.** The dark stops were sampled from a render of the React Bits "Micro Slats" background (classic preset), slats removed.
2. **Glow** from the bottom center: a radial gradient whose alpha follows smootherstep, zero slope at both ends, so it has no visible edge. Twelve stops, so it doesn't band.
3. **Dark only:** a smaller light core, a darker right edge, and a **scrim** up from the bottom (the ease-in alpha of `src/utils/ramp.ts`, peak 0.4) that keeps the glow's core from going white.
4. **Screentone:** dots that grow toward the bottom-right corner, white at 7% in dark, ink at 10% in light. It reads as texture up close and as a soft shade at small sizes.

## Effects on the mark

- **Glass:** the mark fades toward its bottom and has a light inner rim, like Expo's template icon. The rim is the silhouette minus itself eroded, so overlapping parts draw no inner edges.
- **Soft shadow:** a blurred silhouette 18 px down.
- Only the raster icons draw these. On iOS, Liquid Glass adds glass and shadow itself.

## Per platform

| Platform | Files | Look | Notes |
|---|---|---|---|
| iOS | `assets/expo.icon/` | Light and dark | Icon Composer document. The mark is two SVG layers (`a`, `p`) with glass. Icon Composer's fill is only flat or linear, so each background is an image layer shown by appearance. Tinted and clear hide both backgrounds and fill the mark white: they take a layer's luminance, and the near-black a vanished. |
| Android | `assets/images/android-icon-*.png` | Dark | Adaptive icons have no dark variant. The background is a 108 dp canvas showing its middle 72 dp, so the composition is drawn into that middle over a flat fill, which `app.json`'s `adaptiveIcon.backgroundColor` repeats. The mark sits at 72% to stay in the 66 dp safe zone. The monochrome layer (themed icons) is the bare silhouette. |
| Splash | `assets/images/splash-icon*.png` | Both | A flat color with the mark at 120 dp. The images are cropped to the mark, so `imageWidth` is its width. |
| Web | `assets/images/favicon.png` | Dark | 48 px, the small mark, solid: glass blurs at that size. |
| Desktop | `desktop/build/icon.png` | Dark | macOS doesn't mask icons: an 824 pt rounded square with its own shadow, on Apple's 1024 grid. electron-builder picks it up from `build/` when packaging (`bun run dist` in `desktop/`); in development `main.js` sets it as the Dock icon. |
| Fallback | `assets/images/icon.png` | Light | The full composite, unmasked. |

## Changing the icon

1. Edit `CONFIG` at the top of `scripts/app-icon/build.ts` (colors, glow and scrim strength, screentone, which look Android and desktop take). The mark's proportions are `SIZES` in `mark.ts`.
2. Run `bun run icon:build`. It rasterizes with headless Chrome (`CHROME=<path>` to override), rewrites the colors in `app.json`, and, with Xcode installed, renders the iOS icon in all six appearances with Icon Composer's `ictool`. Check those previews: the path is printed at the end.
3. Icons and the splash are native: they only change after `bunx expo prebuild` and a new build (`bun run ios`, `bun run android`). Launchers may keep the old icon until it is reinstalled.
