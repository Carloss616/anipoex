# App icon

The icon, splash and favicon files are generated: read [docs/app-icon.md](../../docs/app-icon.md), change `CONFIG` in `scripts/app-icon/build.ts` and run `bun run icon:build`. Never edit `assets/expo.icon`, the `android-icon-*`, `splash-icon*`, `favicon`, `icon.png` or `desktop/build/icon.png` files by hand.
